# Kurs Sitesi

Yazılım kursları tanıtımı için hazırlanmış çok sayfalı bir web sitesi. HTML ve CSS kullanılarak, ekstra kütüphane veya framework olmadan geliştirilmiştir.

## Özellikler

- 🎨 CSS Grid ile responsive kurs kartları
- 🖱️ Hover efektli, tıklanabilir kurs kartları (her kart ayrı bir linke yönlendiriyor)
- 🧭 Sabit (fixed) navigasyon çubuğu ve arama kutusu
- 🎯 Font Awesome ikon entegrasyonu (Python, HTML5, CSS, JavaScript, React, C ikonları)
- 🌙 Koyu temalı, sayfaya özel arka plan görselleri
- 📄 Sayfa bazlı ayrı CSS dosyaları

## Sayfalar

| Sayfa | Dosya | Açıklama |
|---|---|---|
| Ana Sayfa | `index.html` / `style.css` | Karşılama ekranı, sabit nav bar ve tanıtım yazısı |
| Kurslar | `kurslar.html` / `kurslar.css` | Sunulan kursların (Python, HTML5-CSS, JS, Java, React, C) kart görünümünde listelendiği sayfa |
| Hakkımızda | `hakkımızda.html` / `hakkımızda.css` | Kurum hakkında tanıtım metni |

## Kullanılan Teknolojiler

- HTML5
- CSS3 (Flexbox, Grid, hover/transition efektleri)
- [Font Awesome](https://fontawesome.com/) — ikonlar için

## Kurulum

Herhangi bir kurulum gerektirmez. Projeyi bilgisayarınıza indirip `index.html` dosyasını bir tarayıcıda açmanız yeterlidir.

```bash
kaanyaras0-afk.github.io/codehub-sitesi
```

Ardından `index.html` dosyasını çift tıklayarak tarayıcıda açabilirsiniz.
